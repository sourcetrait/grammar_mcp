# remote_channel_set.rs

## fn set_remote
Each field given is checked before the file is touched, so a bad value is the
caller's `remote::channel::invalid_params`, and `remote::file` stays the file's own
refusal. A new remote needs its `cert`, the one field no command can default.
The answer is the row read back from the file, so it shows what the next read
sees.

## fn unset_remote
An alias the file lacks is refused rather than ignored, so a typo shows. A live
link keeps running: its keys were read when it opened, and `remote channel
close` ends it.
