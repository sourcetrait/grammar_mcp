# msg.rs

The requests the journal's controller sends and each one's answer, every type
cereal data, as a subsys system's messages are.

## struct SubmitRequest
`reserve` is the most bytes the operation's entries and outcome may take, the
caller's to size from the ceiling it negotiated.

## struct Grant
The protocol's `Execute` as data: the one run an admission allows.

## struct Submitted
A duplicate of a finished operation carries its kept outcome as the response
it would have had, its correlation the duplicate's own.

## enum Step, enum Ending
The model's events split by what they need: a step writes an entry alone, an
ending an entry and the outcome it keeps.
